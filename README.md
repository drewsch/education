# База знаний НТ

Статический сайт-справочник по нагрузочному тестированию и производительности: Linux, сеть, протоколы, токены, PostgreSQL, ClickHouse, Redis, Kafka, Camunda/Zeebe, JVM, Go, Python, Kubernetes, микросервисы и system design, теория тестирования, дополнительная литература.

- `content/` — исходники в Markdown (подходят для Obsidian, ссылки `[[...]]` между файлами).
- `tools/` — сборка: `build.py`, шаблон страницы `template.html`, данные раздела «Ядро Linux» `kernel-data.js`.
- `public/` — готовый сайт (`index.html` + `favicon.svg`). Именно эта папка публикуется.

## Деплой на Vercel (бесплатно)

### Вариант 1 — через GitHub (рекомендуется: каждое изменение публикуется само)

1. Создать пустой репозиторий на GitHub и загрузить в него эту папку:
   ```bash
   git init
   git add .
   git commit -m "База знаний НТ"
   git branch -M main
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```
2. Зайти на https://vercel.com → **Add New… → Project** → выбрать репозиторий → **Import**.
3. Настройки подтянутся из `vercel.json` (без сборки, папка `public`). Нажать **Deploy**.
4. Сайт будет доступен по адресу вида `https://<проект>.vercel.app`.

### Вариант 2 — из командной строки

```bash
npm i -g vercel
vercel          # первый раз: логин и создание проекта
vercel --prod   # публикация
```

### Вариант 3 — без Git и CLI

На https://vercel.com можно перетащить папку проекта в окно создания проекта (drag & drop деплой).

## Как обновлять содержимое

1. Править Markdown-файлы в `content/`.
2. Пересобрать сайт:
   ```bash
   pip install markdown
   python3 tools/build.py
   ```
3. Закоммитить изменения (`content/` и `public/index.html`) и отправить в GitHub — Vercel опубликует автоматически.

Новую страницу добавить так: положить `NN Название.md` в `content/` и дописать строку в список `PAGES` в начале `tools/build.py` (файл, id, короткое название, иконка, цвет, группа меню).

## Возможности сайта

- меню по разделам, у каждой темы режимы «Теория» и «Вопросы»;
- поиск по всей базе;
- отметки «прочитано» / «знаю» (сохраняются в браузере);
- случайный вопрос для самопроверки;
- светлая и тёмная тема;
- ссылки на разделы: `#pg`, `#pg/12`, `#kernel/5.q.0`.
