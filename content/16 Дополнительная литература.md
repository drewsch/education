## Как пользоваться списком

1. Не читать всё подряд: идти по [[00 Карта обучения]], а внешние ресурсы открывать, когда тема конспекта пройдена и нужна глубина или практика.
2. Для самопроверки по фундаменту — SadServers и DevOps Exercises.
3. Для глубины по БД — Postgres Pro QPT и Use The Index, Luke.
4. Перед собеседованием — сборники вопросов (DevOps interview, Java Interview) и раздел «Вопросы» каждой страницы базы.
